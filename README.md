# Fraud Detection for E-Commerce and Banking Transactions

This project develops machine learning models to detect fraudulent transactions in:

1. Fraud_Data.csv (E-commerce transactions)
2. creditcard.csv (Bank credit card transactions)

The project covers:
- Data cleaning
- Exploratory Data Analysis
- Geolocation enrichment
- Feature engineering
- Class imbalance handling
- Model training and evaluation
- Explainable AI using SHAP


# Installation
pip install -r requirements.txt

# Datasets
- Fraud_Data.csv
- creditcard.csv
- IpAddress_to_Country.csv

# Models
- Logistic Regression
- Random Forest

# Evaluation Metrics
- AUC-PR
- F1 Score
- Confusion Matrix
